# AI 面试官 · 三期技术方案：跨端移动与小程序

> 版本：v1.0 · 三期启动 · 2026-08-14
> 状态：方案设计完成，待开发
> 配套文档：《需求文档》7.3 节

## 0. 需求回顾

三期目标：将现有 AI 面试官 Web 应用扩展到移动端（iOS/Android）和小程序，实现全平台覆盖。

| 需求项 | 说明 |
|--------|------|
| iOS/Android 双平台 | 通过 WebView 集成，UI 样式适配移动端 |
| 微信小程序 | 通过 WebView 方式集成 |

**核心原则**：最大程度复用现有 Web 代码，降低多端维护成本。

---

## 1. 技术选型总览

| 维度 | 选型 | 说明 |
|------|------|------|
| 移动端框架 | **Capacitor（最新稳定版）** | 与 Vue 3 + Vite 无缝集成，一套 Web 代码生成 iOS/Android 原生应用。开发时通过 `npm install @capacitor/core@latest` 安装 |
| 小程序框架 | **原生微信小程序** | 用 WXML/WXSS/JS 写壳，`<web-view>` 组件加载已部署的 H5 页面 |
| UI 适配 | **TailwindCSS 响应式 + 移动端专属样式** | 断点检测 + 条件渲染切换布局 |
| 原生桥接 | **Capacitor 官方插件 + 自研 bridge 层** | 核心能力（摄像头/麦克风/文件/分享）接入原生 API |
| 具身交互智能体策略 | **先尝试 WebGL → 降级 Lottie** | 移动端优先尝试 WebGL，失败后降级为 Lottie 动画 + TTS 音频 |
| 认证方案 | **JWT + 安全存储** | App 端用 Capacitor Preferences，小程序用 wx.setStorageSync |

## 3. API 基础地址配置策略

### 3.1 问题说明

Capacitor 和小程序的部署模式不同，API 地址发现机制必须区分：

| 部署模式 | H5 来源 | API 地址 |
|----------|---------|----------|
| Capacitor（开发） | 本地 Vite Dev Server | `http://localhost:8000`（直接配置） |
| Capacitor（生产） | 打包进 App 的本地文件 | `https://api.your-domain.com`（固定地址） |
| 小程序 | 远程 HTTPS 服务器 | `https://api.your-domain.com`（与 H5 同源或独立域名） |
| 纯 Web | 远程 HTTPS 服务器 | 根据部署环境决定 |

### 3.2 实现方案

**使用 Vite 环境变量 + 多环境配置文件**：

```bash

.env.capacitor    # Capacitor App 环境
.env.miniprogram  # 小程序嵌入环境
```

**`.env.web`**：
```
VITE_API_BASE_URL=https://api.your-domain.com
VITE_APP_MODE=web
```

**`.env.capacitor`**：
```

VITE_APP_MODE=capacitor
```

**`.env.miniprogram`**：
```

### 3.3 动态检测方案

**在 `src/api/client.ts` 中改造**：

```typescript
// src/api/client.ts
import axios from 'axios'
import { detectHost } from '@/utils/bridge'

// 根据宿主环境动态决定 API 地址
function getApiBaseUrl(): string {
  const host = detectHost()
  
  // Capacitor 开发模式：直接指向本地后端
  if (host === 'capacitor' && import.meta.env.DEV) {
    return 'http://localhost:8000'
  }
  
  // 其他模式：使用环境变量
  return import.meta.env.VITE_API_BASE_URL || 'http://localhost:8000'
}

const client = axios.create({
  baseURL: getApiBaseUrl(),
  timeout: 30000,
})
```

const bridge = require('../../utils/bridge.js')

Page({
  data: {
    webViewUrl: 'https://your-domain.com',  // 已部署的 H5 页面
    loaded: false,
  },

  onLoad() {
    bridge.init()
  },

  onWebViewLoad() {
    this.setData({ loaded: true })
    wx.hideLoading()
  },

  onWebViewError(e) {
    wx.showToast({ title: '加载失败，请重试', icon: 'none' })
  },

  onMessage(e) {
    // 接收 H5 页面发来的消息
    const data = e.detail.data
    if (Array.isArray(data)) {
      data.forEach(msg => this.handleMessage(msg))
    }

  handleMessage(msg) {
    switch (msg.type) {
      case 'share':

        wx.showShareMenu({ withShareTicket: true })
        break
      case 'login':
        // H5 请求小程序登录
        this.handleLogin(msg.payload)
        break
      case 'close':
        // H5 请求关闭小程序
        wx.navigateBack({ delta: 1 })
        break
    }
  },

  handleLogin(payload) {
    // 调用后端换取登录态
    wx.request({
      url: 'https://your-domain.com/api/auth/mini-login',
      method: 'POST',
      data: payload,
      success: (res) => {
        // 将 token 传回 H5
        this.selectComponent('web-view').evalJS(
          `window.__onMiniLoginSuccess(${JSON.stringify(res.data)})`
        )
      },
    })
  },

  onShareAppMessage() {
    return {
      title: 'AI 面试官',
      path: '/pages/index/index',
      imageUrl: '/images/share-cover.png',
    }
  },
})
```

### 5.3 H5 与小程序通信桥接

> **重要**：`wx.miniProgram.postMessage` 在 web-view 中**不是实时通信**——消息只会在用户导航回退或分享时才传递。实时通信必须使用 `evalJS` 方式（从小程序端主动向 H5 注入 JS）。

**通信架构说明**：

```
┌───────────────────────────────────────────────────────────┐
│                     通信方向                               │
│                                                           │
│  H5 ──postMessage──▶ 小程序   (延迟：导航/分享时传递)       │
│  H5 ──URL参数──────▶ 小程序   (H5 跳转时带参，实时)        │
│  小程序 ──evalJS──▶ H5        (实时：由小程序主动调用)     │
│  小程序 ──navigateTo─▶ H5     (跳转 web-view 带参)        │
└───────────────────────────────────────────────────────────┘
```

**实时通信策略**：
- 小程序 → H5（实时）：使用 `this.selectComponent('web-view').evalJS(script)` 注入 JS
- H5 → 小程序（延迟）：`wx.miniProgram.postMessage` + `wx.miniProgram.navigateTo` 带 query 参数
- 对于需要 H5 实时触发小程序能力的场景（如分享、关闭），采用 **URL 带参跳转**：H5 跳转到 `?action=share`，小程序在 `onLoad`/`onShow` 中解析参数并处理

**`miniprogram/utils/bridge.js`**（小程序侧）：

```javascript
class Bridge {
  constructor() {
    this.handlers = {}
    this.webViewContext = null
  }

  // 初始化：获取 web-view 引用用于 evalJS
  setWebViewContext(context) {
    this.webViewContext = context
  }

  // 接收 H5 通过 postMessage 发来的消息（延迟，在分享/回退时触发）
  handleMessages(messages) {
    if (!Array.isArray(messages)) return
    messages.forEach(msg => this.dispatch(msg.type, msg.payload))
  }

  // 接收 H5 通过 URL 参数传递的消息（实时，在 onLoad/onShow 中解析）
  handleUrlParams(params) {
    if (params.action) {
      this.dispatch(params.action, params)
    }
  }

  // 向 H5 实时发送消息（通过 evalJS）
  sendToH5(type, payload) {
    if (!this.webViewContext) return
    const script = `window.__onMiniMessage(${JSON.stringify({ type, payload })})`
    this.webViewContext.evalJS(script)
  }

  dispatch(type, payload) {
    if (this.handlers[type]) {
      this.handlers[type](payload)
    }
  }

  on(type, handler) {
    this.handlers[type] = handler
  }
}

module.exports = new Bridge()
```

**`pages/index/index.js`**（修正：增加实时通信）：

```javascript
const bridge = require('../../utils/bridge.js')

Page({
  data: {
    webViewUrl: '',
    loaded: false,
  },

  onLoad(options) {
    // 解析 H5 通过 URL 传来的 action 参数
    bridge.handleUrlParams(options)
    
    // 根据是否有 action 参数构建 URL
    const baseUrl = 'https://your-domain.com'
    const params = options.action 
      ? `?action=${options.action}&payload=${encodeURIComponent(JSON.stringify(options))}`
      : ''
    this.setData({ webViewUrl: baseUrl + params })
  },

  onShow() {
    // 从 web-view 获取组件引用
    const query = wx.createSelectorQuery()
    query.select('web-view')
      .invokeMethod('getOriginData', '')
      .exec(() => {
        // evalJS 需要在 bindload 之后才能使用
      })
  },

  onWebViewLoad() {
    this.setData({ loaded: true })
    wx.hideLoading()
    // web-view 加载完成后获取引用
    const webview = this.selectComponent('#webView')
    if (webview) {
      bridge.setWebViewContext(webview)
      // 通知 H5：小程序端已就绪
      bridge.sendToH5('ready', {})
    }
  },

  onWebViewError(e) {
    wx.showToast({ title: '加载失败，请重试', icon: 'none' })
  },

  // postMessage 回调（消息延迟传递）
  onMessage(e) {
    const data = e.detail.data
    bridge.handleMessages(data)
  },

  // 处理来自 H5 的消息
  handleShare(payload) {
    wx.showShareMenu({ withShareTicket: true })
  },

  handleLogin(payload) {
    wx.showLoading({ title: '登录中...' })
    wx.request({
      url: 'https://your-domain.com/api/auth/mini-login',
      method: 'POST',
      data: payload,
      success: (res) => {
        wx.hideLoading()
        // 通过 evalJS 实时传回 H5
        bridge.sendToH5('loginSuccess', res.data)
      },
      fail: () => {
        wx.hideLoading()
        bridge.sendToH5('loginFail', { message: '网络错误' })
      },
    })
  },

  onShareAppMessage() {
    return {
      title: 'AI面试官',
      path: '/pages/index/index',
      imageUrl: '/images/share-cover.png',
    }
  },
})
```

**`src/utils/bridge.ts`**（H5 侧，修正）：

```typescript
// H5 与宿主环境通信桥接
export type HostEnv = 'web' | 'capacitor' | 'miniprogram'

export function detectHost(): HostEnv {
  if (typeof (window as any).__wx !== 'undefined') return 'miniprogram'
  if (typeof (window as any).Capacitor !== 'undefined') return 'capacitor'
  return 'web'
}

export function isMiniProgram(): boolean {
  return detectHost() === 'miniprogram'
}

export function isCapacitor(): boolean {
  return detectHost() === 'capacitor'
}

// H5 → 宿主：请求分享
export function requestShare(title: string, url: string): void {
  const host = detectHost()
  if (host === 'miniprogram' && (window as any).__wx?.miniProgram) {
    // 通过跳转 URL 带参请求小程序分享
    ;(window as any).__wx.miniProgram.navigateTo({
      url: `/pages/index/index?action=share&title=${encodeURIComponent(title)}&url=${encodeURIComponent(url)}`,
    })
  } else if (host === 'capacitor') {
    import('@capacitor/share').then(({ Share }) => {
      Share.share({ title, url })
    })
  } else {
    navigator.clipboard.writeText(url)
    alert('链接已复制，快分享给朋友吧！')
  }
}

// H5 → 宿主：关闭当前页面
export function requestClose(): void {
  if (isMiniProgram() && (window as any).__wx?.miniProgram) {
    ;(window as any).__wx.miniProgram.navigateBack({ delta: 1 })
  } else if (isCapacitor()) {
    // 仅 Android 支持程序化退出；iOS App Store 审核禁止此行为
    const isAndroid = /Android/i.test(navigator.userAgent)
    if (isAndroid) {
      import('@capacitor/app').then(({ App }) => {
        App.exitApp()
      }).catch(() => {})
    }
    // iOS：不执行任何操作，App Store 审核要求
  }
}

// H5 → 宿主：发送延迟消息（在分享/导航时传递）
export function postMessageToHost(type: string, payload?: unknown): void {
  if (isMiniProgram() && (window as any).__wx?.miniProgram) {
    ;(window as any).__wx.miniProgram.postMessage({
      data: { type, payload },
    })
  }
}

// 宿主 → H5：监听实时消息
export function onHostMessage(
  handler: (data: { type: string; payload: unknown }) => void
): () => void {
  ;(window as any).__onMiniMessage = handler
  return () => {
    delete (window as any).__onMiniMessage
  }
}

// 宿主 → H5：监听登录结果
export function onLoginResult(
  handler: (success: boolean, data?: unknown) => void
): () => void {
  const onSuccess = (data: unknown) => handler(true, data)
  const onFail = (data: unknown) => handler(false, data)
  ;(window as any).__onMiniLoginSuccess = onSuccess
  ;(window as any).__onMiniLoginFail = onFail
  return () => {
    delete (window as any).__onMiniLoginSuccess
    delete (window as any).__onMiniLoginFail
  }
}

// H5 初始化时调用：通知宿主就绪
export function notifyHostReady(): void {
  postMessageToHost('h5Ready', {})
}

  const windowWidth = ref(window.innerWidth)
  const windowHeight = ref(window.innerHeight)
  const userAgent = ref(navigator.userAgent)

  const isMobile = computed(() => {
    return (
      windowWidth.value < MOBILE_BREAKPOINT ||
      /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(
        userAgent.value
      )
    )
  })

  const isIOS = computed(() => /iPhone|iPad|iPod/i.test(userAgent.value))
  const isAndroid = computed(() => /Android/i.test(userAgent.value))
  const isTouch = computed(() => 'ontouchstart' in window || navigator.maxTouchPoints > 0)
  const isLandscape = computed(() => windowWidth.value > windowHeight.value)

  const handleResize = () => {
    windowWidth.value = window.innerWidth
    windowHeight.value = window.innerHeight
  }

  onMounted(() => {
    window.addEventListener('resize', handleResize)
    window.addEventListener('orientationchange', handleResize)
  })

  onUnmounted(() => {
    window.removeEventListener('resize', handleResize)
    window.removeEventListener('orientationchange', handleResize)
  })

  return { isMobile, isIOS, isAndroid, isTouch, isLandscape, windowWidth, windowHeight }
}
```

async function createAvatarProvider(): Promise<AvatarProvider> {
  const { isMobile } = useDevice()

  if (isMobile.value) {

function testWebGL(): Promise<boolean> {
  return new Promise((resolve) => {
    try {
      const canvas = document.createElement('canvas')

### 8.1 Token 存储

```typescript
// 替换 localStorage 为 Capacitor Preferences
import { Preferences } from '@capacitor/preferences'

const TOKEN_KEY = 'ai_interviewer_token'

async function saveToken(token: string) {
  if (isCapacitor()) {
    await Preferences.set({ key: TOKEN_KEY, value: token })
  } else {
    localStorage.setItem(TOKEN_KEY, token)
  }
}

async function getToken(): Promise<string | null> {
  if (isCapacitor()) {
    const { value } = await Preferences.get({ key: TOKEN_KEY })
    return value
  }
  return localStorage.getItem(TOKEN_KEY)
}

async function clearToken() {
  if (isCapacitor()) {
    await Preferences.remove({ key: TOKEN_KEY })
  } else {
    localStorage.removeItem(TOKEN_KEY)
  }
}

### 8.2 小程序登录

小程序端新增登录流程：
1. 用户在小程序端填写手机号+密码
2. 前端通过 `wx.request` 调用后端 `/api/auth/mini-login` 接口

4. H5 通过 JSSI 接收 token 并存入状态

```python

@router.post("/mini-login")
async def mini_login(request: Request, data: MiniLoginRequest):
    """小程序登录接口"""
    # 验证手机号+密码
    user = await auth_service.authenticate_user(data.phone, data.password)
    if not user:
        raise HTTPException(status_code=401, detail="手机号或密码错误")
    
    # 生成 JWT
    token = auth_service.create_access_token(user.id)
    return {"token": token, "user": user}

async function getStream(constraints: MediaStreamConstraints): Promise<MediaStream> {
  const host = detectHost()

  // Capacitor 环境：尝试原生 Camera，失败降级 Web
  if (host === 'capacitor') {
    try {
      // 检查 WebView 是否支持 getUserMedia
      if (navigator.mediaDevices?.getUserMedia) {
        return await navigator.mediaDevices.getUserMedia(constraints)
      }
      // 降级：使用 Capacitor Camera
      const stream = await Camera.getPhoto({
        quality: 'high',
        allowEditing: false,
      })
      // Camera.getPhoto 返回图片，需特殊处理
      // （实际场景中通常 WebView 已支持）
    } catch {
      // Web 端兜底
    }
  }

  // 小程序环境：通过 JSSI 桥接
  if (host === 'miniprogram') {
    // 小程序需用 wx.createCameraContext / wx.getRecorderManager
    // 通过 JSSI 传递到 H5
    throw new Error('小程序环境不支持 getUserMedia，请使用原生录音')
  }

  // 默认 Web 端
  return await navigator.mediaDevices.getUserMedia(constraints)
}
